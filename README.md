# FocusFix Admin (`focusfix-admin`)

لوحة التحكم الإدارية (SPA) لمنصة **FocusFix** — لإدارة المنظومة التشغيلية بالكامل دون الحاجة لأي تعديلات برمجية.

- **الرابط والدومين:** [https://admin.focusfix.net](https://admin.focusfix.net)
- **التقنيات المستخدمة:**
  - React 18+ (SPA)
  - Vite
  - TypeScript (Strict Mode)
  - Tailwind CSS + RTL
  - React Router
  - TanStack Query v5
  - TanStack Table v8
  - TipTap (Rich Text Blog CMS)
  - Lucide React & Recharts

## المهام والوحدات الرئيسية
1. **نظرة عامة (KPIs):** متابعة الحجوزات اليومية والشهرية ومصادر الحملات.
2. **الحجوزات (Bookings):** جدول الحجوزات، التأكيد، التواصل المباشر عبر واتساب/اتصال، وإدارة الحالات.
3. **مصفوفة الأسعار (Pricing Matrix):** تعديل inline فوري لأسعار الصيانة وضمانها، استيراد وتصدير Excel مع شاشة معاينة الفروقات.
4. **الكتالوج (Catalog):** أنواع الأجهزة، الموديلات، والخدمات.
5. **المناطق والمواعيد (Areas & Slots):** إدارة مناطق التغطية، رسوم الانتقال (0 = مجاناً، أو مبالغ مخصصة)، وسعة الفترات اليومية.
6. **المدونة (Blog CMS):** محرر متقدم TipTap، لوحة تحكم SEO، مراجعات المقالات Revisions.
7. **الرسائل والطلبات:** طلبات عروض الأسعار للموديلات والمناطق غير المدرجة ورسائل التواصل.
8. **المحتوى والإعدادات وسجل التدقيق:** إدارة النصوص وأرقام التواصل وسجل الأمان.
